# Pulse Fitness

A polished, responsive fitness SaaS web app built with React and Vite.

## Features

- Goal, experience, and storage-mode onboarding
- Home dashboard with workout, habits, hydration, and weekly progress
- Custom workout plan and exercise library
- Interactive workout logging modal with timer
- Progress charts and performance metrics
- Nutrition, meals, macros, and hydration tracking
- Community challenges and leaderboard
- Local-first data persistence
- Responsive mobile navigation

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

> The Stripe integration is prepared for a sandbox environment but requires Stripe keys and a server endpoint before real checkout can operate.
